# Public-flow inspiration notes

The product brief asked for BetterHelp as inspiration. Doui intentionally uses only broad category-level ideas common to digital care products: an explanatory landing page, an intake step, therapist discovery, profiles, booking, messaging, and account controls.

No BetterHelp source code, copy, logo, imagery, design assets, proprietary data, or exact layout was copied or used. The Doui brand, wording, mark, colors, typography choices, page composition, onboarding questions, and matching rules are original design decisions.

The public-site fetch available during this build did not provide usable page content, so no claim is made about hidden or non-public BetterHelp behavior.
